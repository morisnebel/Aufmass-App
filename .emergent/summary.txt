**original_problem_statement:**
The user's primary goal is to create two versions of the Aufmaß-App:
1.  A Basic version with limited functionality, intended for a one-time purchase.
2.  A Pro version with all features, intended for a subscription model.

For now, the user wants to finalize the Basic version by hiding or restricting all Pro features, with the ability to easily switch back to the Pro version for future development.

**PRODUCT REQUIREMENTS (for Basic Version):**

*   **Allowed Features:**
    *   Project creation and editing.
    *   Customer management.
    *   Adding photos.
    *   Sketches.
    *   PDF export of project reports.
    *   Checklists with the following limitations:
        *   Maximum of 10 main items per checklist.
        *   Maximum of 5 sub-items per main item.
        *   No further nesting (only 1 level of sub-items).
        *   Maximum of 3 checklist templates.

*   **Disabled/Hidden Features (Pro Features):**
    *   Checklist Features: Unlimited items, template logos, print layout settings, item linking, preview gallery, calculations.
    *   Checklist template import/export.
    *   Project import/export (the button previously labeled PDF-Export in project details).
    *   Multi-project Verschieben (Move) and Referenzen functions on the home screen.
    *   Flächenberechnung (Area Calculator) tool.
    *   Dachberechnung (Roof Calculator) tool.
    *   Doku (Documentation) tool.
    *   The ability for the user to upload their own company logo in settings (the Basic version will have a fixed Aufmassprofi logo).

**User's preferred language**: German

<product_requirements>
The goal is to build a comprehensive measurement application for a roofing company, NEBEL-BEDACHUNG. The application should run on an iPad and mobile devices.

**Core Features:**
1.  **Customer & Project Management:** Create, view, and edit customer and project data.
2.  **Roof Measurement:** Input measurements for various roof types and automatically calculate area. These measurements must be editable later.
3.  **Photo Management:** Add photos to projects, with the ability to draw/annotate on them. Tapping on a photo should not crash the app.
4.  **Checklists:** Create and use checklists for different roofing tasks. Completed checklists must be editable.
5.  **Sketching/Drawing Tool:** A highly interactive canvas where users can:
    *   Draw freehand, lines, circles, and rectangles.
    *   Insert text and dimension arrows.
    *   Import images from the camera or gallery onto the canvas.
    *   Select, move, resize, and rotate any individual element on the canvas.
    *   Delete individual elements.
    *   Saved sketches must be re-editable.
6.  **Reporting:** Generate a PDF report containing all project details (measurements, photos, sketches, checklists) and send it via email.
7.  **Contact Integration:** Import customer information directly from the device's contacts.
8.  **Branding:** The home screen must feature the NEBEL-BEDACHUNG company logo.
</product_requirements>
